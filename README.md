# 投资策略宪法（仅 Reviewer 可修改）

## 目标与风险
- 目标：长期实际购买力增长，控制最大回撤。
- 风险容忍：中性偏稳健。时间框架：3-5 年以上。
- 这不是交易系统，是战略配置建议。绝不预测短期价格。

## 资产范围（允许配置的工具）
- 全球股票宽基 ETF（如美股、发达市场、新兴市场宽基）
- 债券 / 现金等价物
- 黄金
- 比特币
- 单一国家/行业 ETF（受下方上限约束）
- 现金（永远是合法选项）

## 硬约束
- 全部配置 + 现金 = 100%。
- 单一资产上限 25%；加密资产合计上限 10%；最低现金 5%。
  - **澄清（2026-W25）**：「单一资产上限 25%」指**单一国家 / 行业 ETF 的集中度上限**，不约束全球股票宽基、债券、黄金等宽基核心类（这些可高于 25%）。否则股票自上线即 40%/现 37.3% 将「违规」而无人指出——操作语义一贯如此。此为消歧义、非放松；不得据该条强制减仓宽基核心持仓。
- 任何违反约束的配置一律非法，必须先修正再输出。

## 纪律参数（日研究员必须执行）
- EMA 平滑系数 alpha = 0.15
- **EMA 是「持续滚动平滑状态」，绝不每日对当前持仓重新锚定**：每个资产维护一个滚动平滑目标 E，
  每日更新 `E_t = alpha × signal_t + (1−alpha) × E_{t−1}`（系统首日 E_0 = 当前持仓）。
  日研究员必须把每个资产的 E 值写入 state.md 并逐日滚动，**严禁把 E_{t−1} 替换为「当前持仓」**。
  原因：若每日重锚到当前持仓，则单日需要 ≥13.3pp 的信号 gap 才可能突破 ±2pp 无交易带，
  任何渐进式 regime（gap < 13pp）将永远无法累积、组合被永久冻结（2026-W23 复盘已证实此缺陷）。
  正确语义下，持续信号会让 E 几何式累积，数日内自然突破无交易带触发再平衡。
- 交易判定：用 E_t 对照「当前持仓」，仅当 `|E_t − 当前| > 无交易带` 才交易；
  成交后当前持仓向 E_t 靠拢（单步受换手上限约束），E 序列继续滚动。
- **带破出资规则（2026-W25 明文化）**：当某资产 E 带破、需向其靠拢时，资金**由 E 仍低于持仓的资产池按「各自低于持仓的距离」比例出资**；E 高于持仓的资产即便在带内也**不作出资方**（其方向是 EMA 想增持的，不应被反向削减）。这是 06-09 / 06-19 两次再平衡一贯采用的做法，明文化以消除「带破资产如何融资」的规则空白。
  - **（2026-W28 补充·带破出资规则对称化）**：上述规则的对称情形——当某资产 E **向下**带破（需减仓、释放 proceeds）时，proceeds 投向 E **高于**持仓（EMA 想增持）的资产池、按各自**高于**持仓的距离比例分配；E 低于持仓的资产（EMA 减仓方向）不作接收方。07-10 系统第三次再平衡（减金 −2.03pp → 投股/债/现按 1.51:0.97:0.04，BTC 因 E<持仓除外）即此对称做法，明文化以消除「减仓型带破如何分配 proceeds」的规则空白。
- 单资产每日换手上限 = 3 个百分点
- 无交易带 = ±2 个百分点（滚动平滑目标 E 若与当前持仓相差不足 2pp，则维持不动）
- 触发跳变 [TRIGGER]：仅当出现重大结构性事件（如系统性流动性危机、单一资产基本面崩塌）时，
  可绕过换手上限与平滑机制。判定 TRIGGER 时以**单日**真实变动为准，不得把单日剧烈变动改述为「周内」而淡化其严重性。
