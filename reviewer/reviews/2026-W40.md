## 2. 四类失败模式逐项评分 + 证据

### 过度换手：**N/A → 实质为「失活（under-activity）」，不是「过度（over）」**
- 本周期零换手，信号往返（金 10→11→9）全被 EMA 吸收——**在"是否在噪音里瞎动"这个传统问题上，系统满分**：它经历了「金 $4,356→$4,602→$4,146 的完整往返 + BTC +25% 上破 + 一次 regime 翻转」而未做任何交易，事后看完美避开了「追金顶 + 杀 BTC 底」的双重 whipsaw。alpha=0.15 + ±2pp 带 + 单步折算的组合再次被验证为 whipsaw 的有效缓冲。
- **但本周期的过度换手维度须反向审读**：零换手一半是设计（EMA 在带内）、一半是**日研究员根本没在跑**。更危险的是 §开篇的反事实——若按日滚动，金 signal 11 本会把金 E 推到 10.73、几乎触发顶部追买；**是折算法的"欠步"而非系统的主动判断避开了它**。把运气误读为纪律是本维度最大的审计陷阱。
- **结论：传统"过度换手"评分不适用（无交易）；真正的运营病是"失活"——在最需要日度在场的 regime 翻转窗口，系统几乎缺席。** 这是本周期首要隐患（§5-①），并直接触发本周 README 新增「覆盖缺口铁律（W40）」。

### 编造叙事：**A−（在仅有的 4 篇日报内部稳健；但样本过小、过程审计几乎全盲）**
