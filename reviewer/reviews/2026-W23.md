## 2. 四类失败模式逐项评分

### 过度换手 —— A（无过度换手），但暴露**反向缺陷：机制性冻结**
- 本周总换手 **0.0pp**，无任何噪音里瞎动。表面看纪律完美。
- **但根因不是「判断克制」，而是机制坏死**：当前 EMA 实现把平滑目标**每日重新锚定到当前持仓**（`目标 = 当前 + 0.15×(signal − 当前)`）。后果——单日必须出现 **≥13.3pp** 的信号 gap（=2/0.15）才可能突破 ±2pp 无交易带；且因不交易时「当前」不动，**持续信号永远无法累积**。
- 证据：06-06 日报自述「若鹰派 regime 持续，EMA 将逐步向现金倾斜，今日为第一天」——**这在其自身公式下是数学上不可能的**。signal 持稳在 28% 现金、当前持稳 20%，目标将永远是 21.2%、永不累积、永不交易。组合实际处于**永久冻结**状态。
- 处置：本周已修正 README 纪律参数，改为持续滚动 EMA（`E_t = α·signal_t + (1−α)·E_{t−1}`），使持续 regime 在数日内自然突破无交易带。

### 编造叙事 —— B+（基本无编造，叙事有据）
- 每份日报均附带可点击来源，宏观链条（美伊→油价→通胀→利率；热非农→加息）自洽且与引用数据点对应，未见为变动硬凑故事——况且本周根本没有变动，没有「为换手编理由」的动机。
- 扣分项：① 「美伊战争」作为驱动跨 5 天反复出现，有沦为「常青故事」的苗头，需警惕用同一地缘叙事解释一切；② 06-06 的「regime 翻转到加息」叙事很强，但研究员自己已诚实标注「可能是单日过度反应、待 FOMC 验证」——这是加分的自我约束。

### 确认偏误 —— A−（反向证据有分量、且真的影响了决策）
- 【强制反向证据】不是走过场：06-06 的反向证据（强就业=好消息、VIX 仅 ~19、追跌有「卖在低点」风险）**正是把信号压在无交易带、维持不动的实质理由**；BTC 反复以「超卖/资金面投降/仅 5% 小仓位」对冲看空，避免低位减仓。反向证据切实驱动了处置，而非装饰。

## 3. 数据卫生问题（单列）
- **BTC 单日 −13.4% 被改述为「周内 −13%」**：06-03 日报 BTC=$73,469，06-04=$63,649，「较昨日」列实写 −$9,800（即单日 −13.4%），却在正文表述为「周内暴跌约 13%」。单日 −13% 的加密崩跌在 TRIGGER 评估中本应更显著；虽因 BTC 仅 5% 仓位、无交易结论仍可辩护，但**把单日剧烈变动叙述成「周内」会系统性淡化 TRIGGER 触发条件**。已在 README TRIGGER 条款加入「以单日真实变动为准、不得改述为周内」的明确要求。

## 4. README 本周改了什么、为什么
1. **纪律参数 — 修复 EMA 语义（核心改动）**：明确 EMA 为持续滚动状态 `E_t = α·signal_t + (1−α)·E_{t−1}`，禁止每日重锚当前持仓；要求 state.md 维护滚动 E 序列。原因：消除「永久冻结」缺陷，让持续 regime 能在数日内自然落地为再平衡。
2. **TRIGGER 条款 — 加入「单日口径」要求**：判定重大事件以单日真实变动为准，禁止把单日剧烈变动改述为周内而淡化严重性（针对本周 BTC 数据卫生问题）。
3. **当前策略重点 — 从「初始基线」更新为 W23 版**：维持 40/25/10/5/20、**不发 [REBALANCE]**（单日信号不抢跑）；列出 FOMC 验证、BTC 持续空头自然削减、黄金仅留通胀对冲三项观察重点。

**未发 [REBALANCE] 的理由**：本周唯一强信号是 06-06 单日热非农，追单日信号恰是要规避的失败模式；且修复后的持续 EMA 会让真正持续的信号（如 BTC 空头、若 FOMC 确认加息）在数日内自然落地，无需手动强制。

## 5. 风险提示：当前组合最大隐患
1. **利率敏感资产的隐性集中**：06-06 出现股/债/金**三杀**——若加息 regime 在 FOMC 确认，40% 股票 + 10% 黄金会同时受实际利率上行打击，「分散」在 higher-real-rate 情景下相关性趋同、分散失效。修复后的 EMA 虽能调整但需数日，过渡期暴露在外。
2. **校准方向性偏多**：初始判断在 risk-off 转向中两次「偏多」错判，存在系统性高估风险资产动能的倾向；若加息确认而模型仍偏多，会延迟防御。
3. **比特币持续失血**：13 日纪录外流、周内 −17%、第六连阴；虽仅 5% 且方向判断正确，但需确认修复后的 EMA 确实开始逐步削减，而非继续被旧式冻结逻辑卡住。
4. **机制信任**：本周才发现组合此前一直处于「永久冻结」；下次日运行必须正确实现滚动 E 并写入 state.md——这是验证修复是否生效的第一道检验。
