# 投资策略宪法（仅 Reviewer 可修改）

## 目标与风险
- 目标：长期实际购买力增长，控制最大回撤。
- 风险容忍：中性偏稳健。时间框架：3-5 年以上。
- 这不是交易系统，是战略配置建议。绝不预测短期价格。

## 资产范围（允许配置的工具）
- 全球股票宽基 ETF（如美股、发达市场、新兴市场宽基）
- 债券 / 现金等价物
- 黄金
- 比特币
- 单一国家/行业 ETF（受下方上限约束）
- 现金（永远是合法选项）

## 硬约束
- 全部配置 + 现金 = 100%。
- 单一资产上限 25%；加密资产合计上限 10%；最低现金 5%。
  - **澄清（2026-W25）**：「单一资产上限 25%」指**单一国家 / 行业 ETF 的集中度上限**，不约束全球股票宽基、债券、黄金等宽基核心类（这些可高于 25%）。否则股票自上线即 40%/现 37.3% 将「违规」而无人指出——操作语义一贯如此。此为消歧义、非放松；不得据该条强制减仓宽基核心持仓。
- 任何违反约束的配置一律非法，必须先修正再输出。

## 纪律参数（日研究员必须执行）
- EMA 平滑系数 alpha = 0.15
- **EMA 是「持续滚动平滑状态」，绝不每日对当前持仓重新锚定**：每个资产维护一个滚动平滑目标 E，
  每日更新 `E_t = alpha × signal_t + (1−alpha) × E_{t−1}`（系统首日 E_0 = 当前持仓）。
  日研究员必须把每个资产的 E 值写入 state.md 并逐日滚动，**严禁把 E_{t−1} 替换为「当前持仓」**。
  原因：若每日重锚到当前持仓，则单日需要 ≥13.3pp 的信号 gap 才可能突破 ±2pp 无交易带，
  任何渐进式 regime（gap < 13pp）将永远无法累积、组合被永久冻结（2026-W23 复盘已证实此缺陷）。
  正确语义下，持续信号会让 E 几何式累积，数日内自然突破无交易带触发再平衡。
- 交易判定：用 E_t 对照「当前持仓」，仅当 `|E_t − 当前| > 无交易带` 才交易；
  成交后当前持仓向 E_t 靠拢（单步受换手上限约束），E 序列继续滚动。
- **带破出资规则（2026-W25 明文化）**：当某资产 E 带破、需向其靠拢时，资金**由 E 仍低于持仓的资产池按「各自低于持仓的距离」比例出资**；E 高于持仓的资产即便在带内也**不作出资方**（其方向是 EMA 想增持的，不应被反向削减）。这是 06-09 / 06-19 两次再平衡一贯采用的做法，明文化以消除「带破资产如何融资」的规则空白。
  - **（2026-W28 补充·带破出资规则对称化）**：上述规则的对称情形——当某资产 E **向下**带破（需减仓、释放 proceeds）时，proceeds 投向 E **高于**持仓（EMA 想增持）的资产池、按各自**高于**持仓的距离比例分配；E 低于持仓的资产（EMA 减仓方向）不作接收方。07-10 系统第三次再平衡（减金 −2.03pp → 投股/债/现按 1.51:0.97:0.04，BTC 因 E<持仓除外）即此对称做法，明文化以消除「减仓型带破如何分配 proceeds」的规则空白。
- 单资产每日换手上限 = 3 个百分点
- 无交易带 = ±2 个百分点（滚动平滑目标 E 若与当前持仓相差不足 2pp，则维持不动）
- **弱基础论点的 stance 升级须连续同向确认（2026-W30 新增）**：当某资产的 signal 升降是为「反转一个有据可查的弱 / 被反复证伪的经验前提」而做时（典型＝黄金避险 beta≈0，已 17 次证伪），须待 **≥2 个连续同向确认日** 再动 signal，不得据单日相关性追逐。据：07-23 金因单日「油涨金亦涨」+1.8%（首个非-muted 印、却建在 16 次证伪的薄基础上）被升 7→8，次日 07-24 即遭油破 $101 而金反跌 −1.9% 的 whipsaw、撤回 7。虽因「仅一档 + signal 8 下 E asymptote 永不带破 + 换手 0」实现零损失，但这是一次**可避免的信号层 whipsaw**。本条与 W28「debasement 显形须及时上调金、不教条化减金」并不矛盾——**「显形」的门槛即定义为连续同向确认**（研究员 07-24/07-25 已自行收敛至此读法：「reverse bid 需连续同向确认方成立」「显形的门槛是连续同向确认」）。**边界**：事件驱动、且所反转的前提本身稳固的 signal 变动不受本条约束（如 07-22 股 37→38 建于已一手核验的干净 risk-on 收盘、07-24 撤回亦据已核验 risk-off 收盘——这类是对已发生事实的落地，非对单日噪音的追逐）。
- **贵金属临带破再平衡当口的价格核验升级（2026-W32 新增）**：股指收盘按 W26 须次日一手核验后才据以定性，但黄金 signal 一直建于 24-7 盘中 spot（研究员诚实标注「非已核验收盘」）。当某资产（尤指以盘中 spot 定价的贵金属）**`|E_t − 当前持仓| ≥ 1.5pp`（即距 ±2pp 带 ≤0.5pp）**、或某单日 signal 变动将使 `|E_t − 当前持仓|` **突破 2pp 带**时，驱动该 signal 的价格须以**一手源核验的、已完成 session 的价格**（如前一日 COMEX 结算价 / 可核验收盘）为准，**不得仅凭 24-7 盘中 spot**；核验完成前该突破型 signal 变动与由其触发的再平衡**暂挂**至次日核验。这是把 W26/W27 的「收盘须核验」纪律延伸至「临带破触发」当口、消除「系统首个增金再平衡将由未核验 spot 派生的 signal 触发」的规则空白（据：W32 金 signal 7→10 全建于盘中 spot、金 E 8.03 距带 1.28pp、约 3 交易日破带触发系统首个「增金」再平衡）。**边界**：本条**不**改变 alpha、无交易带或换手上限，仅提高「临带破触发」当口对驱动价格的核验标准；带内的常规逐日 spot 定性不受影响。
- 触发跳变 [TRIGGER]：仅当出现重大结构性事件（如系统性流动性危机、单一资产基本面崩塌）时，
  可绕过换手上限与平滑机制。判定 TRIGGER 时以**单日**真实变动为准，不得把单日剧烈变动改述为「周内」而淡化其严重性。
