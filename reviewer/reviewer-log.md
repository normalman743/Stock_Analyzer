## 2026-W23（首个复盘周期，覆盖 06-02 → 06-06，5 篇日报）
**审计结论：日研究员判断纪律总体合格，但发现一个机制级缺陷必须修复。**

- **核心发现 — EMA 永久冻结缺陷**：此前实现把平滑目标每日重锚到当前持仓，导致单日需 ≥13.3pp 信号 gap 才能交易，且持续信号永不累积。06-06 日报自述「regime 持续 EMA 将逐步倾斜」在其公式下数学上不可能。→ 已修 README 纪律参数为持续滚动 EMA `E_t = α·signal_t + (1−α)·E_{t−1}`，要求 state.md 维护 E 序列。
- **四类失败模式评分**：过度换手 A（换手 0，但根因是机制冻结非主动克制）；编造叙事 B+（有据，唯「美伊」常青化苗头）；确认偏误 A−（反向证据切实驱动决策）；校准 期中 2/4。
- **校准（期中，30 天窗口未到期，约 07-02 正式计入）**：06-02 判断 vs 本周——债券✓、BTC✓、股票✗(偏多但跌 -2.9%)、黄金✗(偏多但跌 -3.1%)。**命中率 2/4 = 50%；累计 50%。** 两个错判都是「偏多」方向 → 模型对 risk-off 转向敏感度偏低，需后续观察。
- **数据卫生**：BTC 06-03→06-04 单日 −13.4% 被改述为「周内 −13%」；已在 README TRIGGER 加「以单日口径为准」。
- **README 变更**：① 修 EMA 语义；② TRIGGER 加单日口径；③ 策略重点更新为 W23 版（维持 40/25/10/5/20、不发 [REBALANCE]、列 FOMC/BTC/黄金三观察点）。
- **未发 [REBALANCE]**：唯一强信号是 06-06 单日热非农，追单日=失败模式；修复后的 EMA 会让持续信号自然落地。
- **最大隐患**：加息 regime 若确认→股/债/金三杀、分散失效；校准方向性偏多；下次日运行须验证滚动 E 是否正确落地。
